# 体成分算法 · 公开说明

> **为什么要公开**：体脂率这种数字，如果不告诉用户它是怎么算出来的，
> 那用户就只能"相信"它——这不是健康数据该有的样子。
>
> 本文把 `lib/core/bodycomp.dart` 里**每一行公式**都摊开写清楚，
> 并明确标注：哪些是**公开论文里的原始公式**，哪些是我们**实测反推的校准系数**。
>
> **一句话结论**：这台秤**没有直接测脂肪**。它测的是**电阻**，
> 脂肪率是用电阻（或身高体重年龄）**估算**出来的。

---

## 1. 先理解原理：为什么测电阻能算脂肪

### 1.1 人体的导电性不一样

| 组织 | 含水量 | 导电能力 |
| --- | --- | --- |
| 肌肉、血液、内脏 | 高（约 70~75%）| **好**（含电解质，像盐水）|
| 脂肪 | 低（约 10~20%）| **差**（像塑料）|
| 骨骼 | 低 | 差 |

所以：**同样体重，脂肪多的人电阻更大**。这就是 BIA（生物电阻抗分析）的全部基础。

### 1.2 秤是怎么测的

```
       两只脚，每只脚下有两个电极片（共 4 个）

   左脚前 ─┐              ┌─ 右脚前
           │   ╭──────╮   │
           │   │ 秤面  │   │
           │   ╰──────╯   │
   左脚后 ─┘              └─ 右脚后

电流路径：一脚的电极发出极微弱交流电（<1mA，感觉不到）
          → 经过小腿、大腿、骨盆 → 另一脚电极回来
          → 中间测电压降 → 欧姆定律算出阻抗（Ω）
```

**关键**：必须**双脚赤脚同时踩住**四个电极，电路才闭合。
单脚、穿袜子、脚底太干 → 阻抗测出来是 **0**，体脂率就无从算起。

> 这不是软件能控制的。任何"发送某个命令就能开启阻抗"的说法都是错的——
> 我们做过 A/B 对照实验验证（见 [协议文档](PROTOCOL.md) 坑 7）。

### 1.3 这台秤给我们的原始数据

秤在测量完成的锁定包里给出**两个 ADC 值**（可以理解为左右两路的原始读数）：

```
阻抗1 = (d[4] << 8 | d[5])   ← 单位欧姆
阻抗2 = (d[6] << 8 | d[7])
```

正常范围大约 **100 ~ 1500 Ω**。超出这个范围的值一律视为无效。

---

## 2. 第一步：把两个阻抗合成一个

论文里的公式都只接受**一个**阻抗值，但秤给了两个。我们的做法：

```
合成阻抗 R = (阻抗1 + 阻抗2) × 0.675
```

### 那个 0.675 是怎么来的

⚠️ **这个系数不是论文里的，是我们实测反推的**。

做法：拿官方蚂蚁健康 App 在同一时刻显示的体脂率，反推什么样的 R 能让公式对上。
多组数据拟合后发现约 0.675 能稳定命中（例如 79.95kg + 阻抗 [405, 367] → 官方显示 37.7%）。

**为什么会有两个 ADC**：可能是一路是 50kHz、另一路是另一个频率（多频 BIA 的常见做法），
两路合成的目的通常是抵消接触电阻的影响。但厂商没公开，我们的理解仅为推断。

### 有效性检查

```
只有当合成后的 R 落在 100 ~ 1500 Ω 之间，才算有效阻抗
```

---

## 3. BMI（唯一不依赖估算的指标）

```
BMI = 体重(kg) ÷ 身高(m)²
```

例：55.75kg、163cm → 55.75 ÷ 1.63² = **21.0**

**BMI 不含性别、不含年龄**。这是世界卫生组织（WHO）的定义，
所有软件算出来的 BMI 都应该一样（只要体重身高一样）。

所以：切换性别 BMI 不变，是**正确行为**，不是 bug。

---

## 4. 男性体脂率：Deurenberg 公式（不用阻抗）

```
体脂率(%) = 1.10 × BMI + 0.23 × 年龄 − 11.22
```

**来源**：Deurenberg 等人 1991 年发表的种族修正公式（日本人群版本）。
这是**公开论文的原始公式**，我们只用了固定系数，没有改。

**注意：男性公式里没有阻抗**。也就是说，只要知道身高体重年龄，
哪怕没踩好电极、阻抗为 0，男性体脂率照样能算。

**实测核对**：79.8kg 男性样本 → 算出 25.4%，与官方 App 显示一致。

模型标记：`deurenberg_jp_male`

---

## 5. 女性体脂率：Segal 公式（必须用阻抗）

女性走另一套公式，需要阻抗。

### 5.1 先算"去脂体重"（FFM，Fat-Free Mass）

```
FFM = 体重 − 脂肪的重量    ← 也就是肌肉、骨骼、水分、内脏的总和
```

Segal 公式不直接给体脂率，而是先估 FFM，再用 `100 × (体重 − FFM) ÷ 体重` 反推。

### 5.2 两个分支：先试 3C，不行再 3D

**分支 A（3C 式，适用于体脂 < 30% 的人）**

```
FFM_A = 10.43485
      + 0.00064602 × 身高²(cm²)
      − 0.01397   × R(合成阻抗)
      + 0.42087   × 体重(kg)
```

先用 A 算出结果，再用它反推体脂率，**如果结果 < 30%，就用这个值**。

**分支 B（3D 式，适用于体脂 ≥ 30% 的人）**

```
FFM_B = 9.37938
      + 0.00091186 × 身高²(cm²)
      − 0.01466   × R
      + 0.29990   × 体重
      − 0.07012   × 年龄
```

> 为什么分两段？因为 Segal 公式本来就是针对不同肥胖程度拟合的两组回归线，
> 胖的人用 A 式会系统性低估 FFM。两段拼接是论文的原意。

**来源**：Segal 等人 1988 年发表于 *American Journal of Clinical Nutrition* 的公式。
原式系数是公开的，我们直接用。

**注意身高单位**：公式里的身高是 **cm**，平方后是 cm²（如 163² = 26569）。
不是 m²。这里搞错会差 10000 倍。

### 5.3 合理性夹紧

```
FFM 被限制在 体重的 35% ~ 97% 之间
```

防止极端输入（比如阻抗 100Ω 配 30kg 体重）算出离谱结果。

**实测核对**：79.95kg + 阻抗 [405, 367] → 合成 R = 521Ω → 算出 37.7%，与官方一致。

模型标记：`segal_3c_female_lt30` / `segal_3d_female_ge30`

### 5.4 女性没有阻抗时的兜底

```
体脂率(%) = 1.10 × BMI + 0.23 × 年龄 − 5.4
```

这是 Deurenberg 公式的**女性版本**（男版末尾是 −11.22，女版是 −5.4）。
注意和男性公式对比：同样的 BMI 和年龄，女性算出来会高 **5.82 个百分点**——
这符合生理事实（女性正常体脂率本来就高于男性）。

模型标记：`deurenberg_jp_female`

---

## 6. 最终夹紧

```
男性体脂率限制在 3% ~ 60%
女性体脂率限制在 8% ~ 60%
```

下限定得不同是因为：男性低于 3% 体脂在生理上几乎不可能（竞技健美极限约 4~5%），
女性低于 8% 会影响内分泌。超过 60% 则基本是测量错误。
---

## 7. 其余指标：都是从体脂率"推"出来的

⚠️ **先说清楚一件事**：这台秤只测了**体重**和**阻抗**两个量。
下面所有指标都是从上一步算出的体脂率**推导**的，不是分别测量的。

所以理解它们的可信度，要按这个顺序：

```
可信度：体重（直接测） > BMI（纯数学） > 体脂率（公式估算）> 其他指标（二次推导）
```

### 7.1 脂肪量 / 去脂体重

```
脂肪量(kg)   = 体重 × 体脂率%
去脂体重(kg) = 体重 − 脂肪量
```

纯算术，没有额外假设。

### 7.2 骨量：固定百分比

```
骨量% = 男性 4.5%   /   女性 4.0%
骨量(kg) = 体重 × 骨量%
```

⚠️ **这是写死的常数，不是测量的**。真实骨密度需要 DEXA（X 光）才能测，
任何家用体脂秤的"骨量"都是按人群平均值给的估计值。
我们的取值来自实测反推官方 App 的显示值。

### 7.3 肌肉量：用减法倒推

```
肌肉% = 100 − 体脂% − 骨量%      （结果限制在 20% ~ 95%）
肌肉量(kg) = 体重 × 肌肉%
```

这个逻辑是"除了脂肪和骨头，剩下的算肌肉"。
严格说这个"剩下"里还包含内脏、水分、结缔组织，但厂商习惯这么归类。

### 7.4 水分率：去脂体重 × 系数

```
水分% = (100 − 体脂%) × 系数
系数：男性 0.7185   /   女性 0.8475
（结果限制在 25% ~ 80%）
```

生理学依据：去脂组织（肌肉内脏）含水约 73%；脂肪组织含水约 10~20%。

⚠️ 女性系数 0.8475 明显高于常用的 0.73，这是实测反推官方 App 的结果。
可能有厂商自己的修正模型，我们按实测值走。

### 7.5 蛋白质：直接按体重比例

```
蛋白质量(kg) = 体重 × 系数
系数：男性 0.163   /   女性 0.05
```

⚠️ **这里有个需要指出的疑点**：

| 来源 | 男性蛋白占比 | 女性蛋白占比 |
| --- | --- | --- |
| 生理学常识 | 约 16~18% | 约 16~18% |
| 我们的实现 | 0.163（合理）| **0.05（明显偏低）** |

女性的 0.05 是从官方 App 显示值反推出来的，
**从生理学角度看这个数字不太合理**——它会让 55.75kg 的女性只显示 2.8kg 蛋白质，
而实际应该在 9kg 左右。

我们保留它，是为了"和官方 App 保持一致"；如果你更看重生理合理性，
可以把这个系数改成 0.16 左右。**这一项请谨慎引用。**

### 7.6 骨骼肌率：肌肉量 × 系数

```
骨骼肌% = 肌肉% × 系数
系数：男性 0.548   /   女性 0.651
（结果限制在 10% ~ 70%）
```

"骨骼肌"是肌肉里附着在骨头上的那部分（区别于心肌和平滑肌）。
通常占肌肉总量的 55~65%，男女系数不同是实测反推的结果。

### 7.7 皮下脂肪：体脂 × 系数

```
皮下脂肪% = 体脂% × 系数
系数：男性 0.7165   /   女性 0.72
（结果限制在 1% ~ 体脂%）
```

体脂分成"皮下脂肪"（捏得到的那层）和"内脏脂肪"（包在器官周围的）。
这个系数表示约 72% 的脂肪在皮下。

## 8. 完整计算流程（伪代码）

```
输入：体重 W(kg)、身高 H(cm)、年龄 A、性别、阻抗 [i1, i2]

① BMI = W ÷ (H/100)²

② 合成阻抗 R = (i1 + i2) × 0.675
   若 R 不在 100~1500 区间 → 视为无有效阻抗

③ 算体脂率 bf：
   若 性别=男：
       bf = 1.10×BMI + 0.23×A − 11.22          ← 不需要阻抗
   否则（女）：
       若 R 有效：
           FFM_A = 10.43485 + 0.00064602×H² − 0.01397×R + 0.42087×W
           若 100×(W−FFM_A)/W < 30  →  bf = 100×(W−FFM_A)/W
           否则：
               FFM_B = 9.37938 + 0.00091186×H² − 0.01466×R + 0.29990×W − 0.07012×A
               bf = 100×(W−FFM_B)/W
           其中 FFM 夹紧到 W×0.35 ~ W×0.97
       否则（无阻抗）：
           bf = 1.10×BMI + 0.23×A − 5.4       ← 女性兜底公式

④ bf 夹紧：男 3~60，女 8~60

⑤ 派生：
   脂肪量        = W × bf/100
   去脂体重      = W − 脂肪量
   骨量%         = 男 4.5 / 女 4.0
   肌肉%         = 100 − bf − 骨量%（限 20~95）
   水分%         = (100−bf) × (男 0.7185 / 女 0.8475)（限 25~80）
   蛋白质量      = W × (男 0.163 / 女 0.05)
   骨骼肌%       = 肌肉% × (男 0.548 / 女 0.651)（限 10~70）
   皮下脂肪%     = bf × (男 0.7165 / 女 0.72)（限 1~bf）

⑥ 所有输出保留 1 位小数
```

对应代码：`lib/core/bodycomp.dart`（76 行，无外部依赖，可单独测试）

## 8.5 实测输出：同一组数据，男女各算出什么

拿 `55.75kg / 163cm / 24岁 / 阻抗 430+387` 这组数据，跑完整算法：

| 指标 | 男性公式 | 女性公式 | 差异 | 说明 |
| --- | --- | --- | --- | --- |
| BMI | **21.0** | **21.0** | **相同** | 纯数学，不含性别 |
| 体脂率 | 17.4% | 22.2% | +4.8 pp | 男女走不同公式 |
| 水分率 | 59.4% | 65.9% | +6.5 pp | 女性去脂组织含水系数更高 |
| 骨骼肌率 | 42.8% | 48.0% | +5.2 pp | 系数 0.548 vs 0.651 |
| 皮下脂肪 | 12.5% | 16.0% | +3.5 pp | 随体脂率走高 |
| 蛋白质量 | **9.1 kg** | **2.8 kg** | 差 6.3 kg | ⚠️ 女性系数 0.05 的已知疑点（见 §7.5）|

模型标记：男性 `deurenberg_jp_male` · 女性 `segal_3c_female_lt30`（合成阻抗 551.5Ω）

> 这张表最想说明两件事：
> 1. **BMI 一模一样**——切换性别它不变是设计如此
> 2. **蛋白质那一行是异常**——男女不该差 3 倍，这是逆向系数的遗留问题

## 10. 这套算法的局限（重要）

### 10.1 和秤屏幕会差零点几个百分点

秤屏用的是厂商**私有算法**（不公开）。我们用的是公开公式 + 校准系数，
所以两边会差 **0.3~0.5 个百分点**左右。

**BMI 永远一致**（纯数学，没有算法分歧的余地）。

### 10.2 阻抗受水分影响极大

同样的身体，不同状态下阻抗可能差几十欧姆，对应体脂率差 2~5 个百分点：

| 情况 | 阻抗 | 体脂率读数 |
| --- | --- | --- |
| 早晨刚起床（略脱水）| 偏高 | 偏高 |
| 刚喝完水 / 刚运动完（充血）| 偏低 | 偏低 |
| 刚洗完澡（皮肤湿润）| 偏低 | 偏低 |
| 冬天脚底干燥 | 偏高 | 偏高 |

**正确用法**：固定在同一状态测（比如每天早上起床后、排尿后、喝水前），
看**趋势**而不是看单次数值。

### 10.3 不适合的人群

- 孕妇（体液分布特殊）
- 运动员 / 健美（体脂极低时公式外推不准）
- 水肿、腹水、透析患者（体液异常）
- 儿童青少年（生长阶段公式不适用）
- 装有心脏起搏器的人（微弱电流风险，**绝对不要用**）

### 10.4 不是医疗设备

所有数字都是**估算值**，仅供个人趋势参考，不能用于诊断、治疗或任何医疗决策。
需要准确体成分请做 DEXA（双能 X 射线吸收法）或 MRI。
