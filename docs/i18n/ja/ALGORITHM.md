# 体組成アルゴリズム · 公開解説

> **なぜ公開するのか**：体脂肪率のような数字は、どう計算したのかをユーザーに示さなければ、
> ユーザーはそれを「信じる」しかない——健康データはそうあるべきではない。
>
> 本文は `lib/core/bodycomp.dart` の**各式を 1 行ずつ**開いて書き出し、
> どれが**公開論文の原式**で、どれが私たちが**実測から逆算した校正係数**かを明示する。
>
> **一行の結論**：この秤は**脂肪を直接測っていない**。測っているのは**電気抵抗**であり、
> 脂肪率は抵抗（または身長・体重・年齢）から**推定**した値だ。

---

## 1. まず原理：なぜ抵抗を測ると脂肪が分かるのか

### 1.1 人体は部位によって電気の通しやすさが違う

| 組織 | 含水量 | 導電性 |
| --- | --- | --- |
| 筋肉、血液、内臓 | 高（約 70~75%）| **良い**（電解質を含み、食塩水のよう）|
| 脂肪 | 低（約 10~20%）| **悪い**（プラスチックのよう）|
| 骨 | 低 | 悪い |

したがって：**同じ体重なら、脂肪の多い人のほうが抵抗が大きい**。これが BIA（生体電気インピーダンス法）の基礎のすべてだ。

### 1.2 秤はどう測るのか

```
       両足で、片足あたり電極パッドが 2 枚（合計 4 枚）

   左足前 ─┐              ┌─ 右足前
           │   ╭──────╮   │
           │   │ 秤面 │   │
           │   ╰──────╯   │
   左足後 ─┘              └─ 右足後

電流経路：一方の足の電極からごく微弱な交流電流を流す（<1mA、体感できない）
          → 下腿、大腿、骨盤を通る → もう一方の足の電極へ戻る
          → 途中の電圧降下を測る → オームの法則でインピーダンス（Ω）を算出
```

**要点**：**両足を裸足で同時に** 4 つの電極に当てないと回路が閉じない。
片足、靴下、足裏の乾燥 → インピーダンスは **0** になり、体脂肪率は計算のしようがない。

> これはソフトウェアで制御できるものではない。「あるコマンドを送ればインピーダンスが有効になる」という主張はすべて誤りだ——
> A/B 対照実験で検証済み（[プロトコル文書](PROTOCOL.md) 落とし穴 7 参照）。

### 1.3 この秤が与えてくる生データ

秤は測定完了時の確定パケットで**2 つの ADC 値**を与える（左右 2 系統の生読み値と考えてよい）：

```
インピーダンス1 = (d[4] << 8 | d[5])   ← 単位はオーム
インピーダンス2 = (d[6] << 8 | d[7])
```

正常範囲はおよそ **100 ~ 1500 Ω**。この範囲を外れる値は一律で無効とみなす。

## 2. ステップ 1：2 つのインピーダンスを 1 つに合成する

論文の式はいずれも**1 つ**のインピーダンス値しか受け取らないが、秤は 2 つを返してくる。私たちのやり方は：

```
合成インピーダンス R = (インピーダンス1 + インピーダンス2) × 0.675
```

### その 0.675 はどこから来たのか

⚠️ **この係数は論文のものではなく、私たちが実測から逆算したものだ**。

やり方：公式の Ant Afu 健康 App が同じ時刻に表示する体脂肪率を使い、どんな R なら式が一致するかを逆算した。
複数組のデータでフィッティングしたところ、約 0.675 で安定して一致した（例：79.95kg + インピーダンス [405, 367] → 公式表示 37.7%）。

**なぜ ADC が 2 つあるのか**：一方が 50kHz、もう一方が別の周波数である可能性が高い（多周波 BIA でよくある方式）。
2 系統を合成する目的は通常、接触抵抗の影響を打ち消すことだ。ただしメーカーは公開しておらず、私たちの理解は推測にすぎない。

### 有効性の確認

```
合成後の R が 100 ~ 1500 Ω の間にあるときだけ、有効なインピーダンスとみなす
```

## 3. BMI（推定に依存しない唯一の指標）

```
BMI = 体重(kg) ÷ 身長(m)²
```

例：55.75kg、163cm → 55.75 ÷ 1.63² = **21.0**

**BMI に性別は入らず、年齢も入らない**。これは世界保健機関（WHO）の定義であり、
どのソフトでも BMI は同じになるはずだ（体重と身長が同じなら）。

したがって：性別を切り替えても BMI が変わらないのは**正しい挙動**であり、バグではない。

---

## 4. 男性の体脂肪率：Deurenberg の式（インピーダンス不要）

```
体脂肪率(%) = 1.10 × BMI + 0.23 × 年齢 − 11.22
```

**出典**：Deurenberg らが 1991 年に発表した人種補正版の式（日本人集団向け）。
これは**公開論文の原式**であり、私たちは固定係数を使っただけで変更は加えていない。

**注意：男性の式にインピーダンスは入らない**。つまり身長・体重・年齢が分かれば、
電極の接触が悪くインピーダンスが 0 でも、男性の体脂肪率は算出できる。

**実測照合**：79.8kg の男性サンプル → 25.4% と算出され、公式 App の表示と一致。

モデルタグ：`deurenberg_jp_male`

---

## 5. 女性の体脂肪率：Segal の式（インピーダンス必須）

女性は別の式を使い、インピーダンスが必要になる。

### 5.1 まず「除脂肪体重」（FFM、Fat-Free Mass）を求める

```
FFM = 体重 − 脂肪の重量    ← つまり筋肉、骨、水分、内臓の合計
```

Segal の式は体脂肪率を直接与えず、まず FFM を推定し、`100 × (体重 − FFM) ÷ 体重` で逆算する。

### 5.2 2 つの分岐：まず 3C を試し、だめなら 3D

**分岐 A（3C 式、体脂肪 < 30% の人に適用）**

```
FFM_A = 10.43485
      + 0.00064602 × 身長²(cm²)
      − 0.01397   × R（合成インピーダンス）
      + 0.42087   × 体重(kg)
```

まず A で結果を出し、それで体脂肪率を逆算する。**結果が < 30% ならその値を採用する**。

**分岐 B（3D 式、体脂肪 ≥ 30% の人に適用）**

```
FFM_B = 9.37938
      + 0.00091186 × 身長²(cm²)
      − 0.01466   × R
      + 0.29990   × 体重
      − 0.07012   × 年齢
```

> なぜ 2 段に分けるのか。Segal の式はもともと肥満度の異なる 2 群に当てはめた 2 本の回帰式であり、
> 肥満の人が A 式を使うと FFM を系統的に過小評価する。2 段の使い分けは論文本来の意図だ。

**出典**：Segal らが 1988 年に *American Journal of Clinical Nutrition* に発表した式。
原式の係数は公開されており、私たちはそのまま使っている。

**身長の単位に注意**：式の中の身長は **cm** で、2 乗すると cm²（例 163² = 26569）。
m² ではない。ここを間違えると 10000 倍ずれる。

### 5.3 妥当範囲へのクランプ

```
FFM は体重の 35% ~ 97% の範囲に制限する
```

極端な入力（たとえばインピーダンス 100Ω で体重 30kg）から的外れな結果が出るのを防ぐ。

**実測照合**：79.95kg + インピーダンス [405, 367] → 合成 R = 521Ω → 37.7% と算出され、公式と一致。

モデルタグ：`segal_3c_female_lt30` / `segal_3d_female_ge30`

### 5.4 女性でインピーダンスが無い場合のフォールバック

```
体脂肪率(%) = 1.10 × BMI + 0.23 × 年齢 − 5.4
```

これは Deurenberg の式の**女性版**だ（男性版の末尾は −11.22、女性版は −5.4）。
男性の式と比べてみると：同じ BMI と年齢なら女性のほうが **5.82 ポイント**高く出る——
これは生理学的な事実に合致する（女性の正常な体脂肪率はもともと男性より高い）。

モデルタグ：`deurenberg_jp_female`

---

## 6. 最終クランプ

```
男性の体脂肪率は 3% ~ 60% に制限する
女性の体脂肪率は 8% ~ 60% に制限する
```

下限が違うのは：男性は体脂肪 3% 未満が生理的にほぼ不可能であり（競技ボディビルの限界でも約 4~5%）、
女性は 8% 未満で内分泌に影響が出るためだ。60% を超えるのはほぼ測定エラーである。
---

## 7. 残りの指標：すべて体脂肪率から「導出」したもの

⚠️ **まず 1 つ明確にしておく**：この秤が測っているのは**体重**と**インピーダンス**の 2 量だけだ。
以下の指標はすべて、前段で算出した体脂肪率から**導出**したものであり、個別に測定した値ではない。

したがって信頼度は次の順で理解するとよい：

```
信頼度：体重（直接測定） > BMI（純粋な数学） > 体脂肪率（式による推定）> その他の指標（二次導出）
```

### 7.1 脂肪量 / 除脂肪体重

```
脂肪量(kg)   = 体重 × 体脂肪率%
除脂肪体重(kg) = 体重 − 脂肪量
```

単なる算術であり、追加の仮定は無い。

### 7.2 骨量：固定のパーセント

```
骨量% = 男性 4.5%   /   女性 4.0%
骨量(kg) = 体重 × 骨量%
```

⚠️ **これはハードコードされた定数で、測定値ではない**。本当の骨密度は DEXA（X 線）でしか測れず、
家庭用体組成計の「骨量」はすべて母集団平均に基づく推定値だ。
私たちの値は、公式 App の表示値から実測で逆算したもの。

### 7.3 筋肉量：引き算で逆算する

```
筋肉% = 100 − 体脂肪% − 骨量%      （結果は 20% ~ 95% に制限）
筋肉量(kg) = 体重 × 筋肉%
```

この論理は「脂肪と骨を除いた残りを筋肉とみなす」。
厳密にはこの「残り」には内臓、水分、結合組織も含まれるが、メーカーは慣例的にこう分類する。

### 7.4 水分率：除脂肪体重 × 係数

```
水分% = (100 − 体脂肪%) × 係数
係数：男性 0.7185   /   女性 0.8475
（結果は 25% ~ 80% に制限）
```

生理学的な根拠：除脂肪組織（筋肉・内臓）の含水量は約 73%、脂肪組織の含水量は約 10~20%。

⚠️ 女性の係数 0.8475 は一般に使われる 0.73 より明らかに高い。これは公式 App の表示から実測で逆算した結果だ。
メーカー独自の補正モデルがある可能性があるが、私たちは実測値に従っている。

### 7.5 タンパク質：体重比で直接与える

```
タンパク質量(kg) = 体重 × 係数
係数：男性 0.163   /   女性 0.05
```

⚠️ **ここに指摘すべき疑義がある**：

| 出典 | 男性のタンパク質比率 | 女性のタンパク質比率 |
| --- | --- | --- |
| 生理学の常識 | 約 16~18% | 約 16~18% |
| 本実装 | 0.163（妥当）| **0.05（明らかに低すぎる）** |

女性の 0.05 は公式 App の表示値から逆算したものだが、
**生理学的に見るとこの数値は妥当ではない**——55.75kg の女性でタンパク質が 2.8kg としか表示されないが、
実際は 9kg 前後になるはずだ。

「公式 App と一致させる」ためにそのまま残している。生理学的な妥当性を重視するなら、
この係数を 0.16 前後に変えてよい。**この項目の引用は慎重に。**

### 7.6 骨格筋率：筋肉量 × 係数

```
骨格筋% = 筋肉% × 係数
係数：男性 0.548   /   女性 0.651
（結果は 10% ~ 70% に制限）
```

「骨格筋」は筋肉のうち骨に付着する部分（心筋・平滑筋と区別される）。
通常は筋肉全体の 55~65% を占める。男女で係数が違うのは実測から逆算した結果だ。

### 7.7 皮下脂肪：体脂肪 × 係数

```
皮下脂肪% = 体脂肪% × 係数
係数：男性 0.7165   /   女性 0.72
（結果は 1% ~ 体脂肪% に制限）
```

体脂肪は「皮下脂肪」（つまめる層）と「内臓脂肪」（臓器の周りを包む層）に分かれる。
この係数は脂肪の約 72% が皮下にあることを意味する。

## 8. 計算フローの全体（擬似コード）

```
入力：体重 W(kg)、身長 H(cm)、年齢 A、性別、インピーダンス [i1, i2]

① BMI = W ÷ (H/100)²

② 合成インピーダンス R = (i1 + i2) × 0.675
   R が 100~1500 の区間に入らない → 有効なインピーダンス無しとみなす

③ 体脂肪率 bf を算出：
   性別=男性 の場合：
       bf = 1.10×BMI + 0.23×A − 11.22          ← インピーダンス不要
   そうでない（女性）場合：
       R が有効なら：
           FFM_A = 10.43485 + 0.00064602×H² − 0.01397×R + 0.42087×W
           100×(W−FFM_A)/W < 30 なら  →  bf = 100×(W−FFM_A)/W
           そうでなければ：
               FFM_B = 9.37938 + 0.00091186×H² − 0.01466×R + 0.29990×W − 0.07012×A
               bf = 100×(W−FFM_B)/W
           ここで FFM は W×0.35 ~ W×0.97 にクランプ
       そうでない（インピーダンス無し）：
           bf = 1.10×BMI + 0.23×A − 5.4       ← 女性のフォールバック式

④ bf をクランプ：男 3~60、女 8~60

⑤ 派生：
   脂肪量         = W × bf/100
   除脂肪体重     = W − 脂肪量
   骨量%          = 男 4.5 / 女 4.0
   筋肉%          = 100 − bf − 骨量%（20~95 に制限）
   水分%          = (100−bf) × (男 0.7185 / 女 0.8475)（25~80 に制限）
   タンパク質量   = W × (男 0.163 / 女 0.05)
   骨格筋%        = 筋肉% × (男 0.548 / 女 0.651)（10~70 に制限）
   皮下脂肪%      = bf × (男 0.7165 / 女 0.72)（1~bf に制限）

⑥ すべての出力は小数 1 桁で丸める
```

対応するコード：`lib/core/bodycomp.dart`（76 行、外部依存なし、単体テスト可能）

## 10. このアルゴリズムの限界（重要）

### 10.1 秤の画面とは 0 数ポイントずれる

秤の画面はメーカーの**独自アルゴリズム**（非公開）を使っている。こちらは公開式 + 校正係数なので、
両者は **0.3~0.5 ポイント**ほどずれる。

**BMI は常に一致する**（純粋な数学で、アルゴリズムの分岐が入り込む余地がない）。

### 10.2 インピーダンスは水分の影響を極めて強く受ける

同じ体でも状態によってインピーダンスは数十オーム変わり、体脂肪率にして 2~5 ポイントの差になる：

| 状況 | インピーダンス | 体脂肪率の読み値 |
| --- | --- | --- |
| 朝起きた直後（やや脱水）| 高め | 高め |
| 水を飲んだ直後 / 運動直後（充血）| 低め | 低め |
| 入浴直後（皮膚が湿っている）| 低め | 低め |
| 冬に足裏が乾燥 | 高め | 高め |

**正しい使い方**：同じ状態で測るように固定する（たとえば毎朝起床後、排尿後、飲水前）。
**トレンド**を見るのであって、1 回の数値を見るのではない。

### 10.3 適合しない人

- 妊婦（体液分布が特殊）
- アスリート / ボディビルダー（体脂肪が極端に低いと式の外挿が不正確）
- 浮腫、腹水、透析患者（体液が異常）
- 小児・青少年（成長段階では式が適用できない）
- 心臓ペースメーカー装着者（微弱電流のリスクがあり、**絶対に使用しないこと**）

### 10.4 医療機器ではない

すべての数値は**推定値**であり、個人のトレンド参考用にすぎず、診断・治療・その他いかなる医療判断にも使えない。
正確な体組成が必要なら DEXA（二重エネルギー X 線吸収法）または MRI を受けること。
