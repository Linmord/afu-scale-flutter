# 體成分演算法 · 公開說明

> **為什麼要公開**：體脂率這種數字，如果不告訴使用者它是怎麼算出來的，
> 那使用者就只能「相信」它——這不是健康資料該有的樣子。
>
> 本文把 `lib/core/bodycomp.dart` 裡**每一行公式**都攤開寫清楚，
> 並明確標註：哪些是**公開論文裡的原始公式**，哪些是我們**實測反推的校準係數**。
>
> **一句話結論**：這台秤**沒有直接測脂肪**。它測的是**電阻**，
> 脂肪率是用電阻（或身高體重年齡）**估算**出來的。

---

## 1. 先理解原理：為什麼測電阻能算脂肪

### 1.1 人體的導電性不一樣

| 組織 | 含水量 | 導電能力 |
| --- | --- | --- |
| 肌肉、血液、內臟 | 高（約 70~75%）| **好**（含電解質，像鹽水）|
| 脂肪 | 低（約 10~20%）| **差**（像塑膠）|
| 骨骼 | 低 | 差 |

所以：**同樣體重，脂肪多的人電阻更大**。這就是 BIA（生物電阻抗分析）的全部基礎。

### 1.2 秤是怎麼測的

```
       兩隻腳，每隻腳下有兩個電極片（共 4 個）

   左腳前 ─┐              ┌─ 右腳前
           │   ╭──────╮   │
           │   │ 秤面  │   │
           │   ╰──────╯   │
   左腳後 ─┘              └─ 右腳後

電流路徑：一腳的電極發出極微弱交流電（<1mA，感覺不到）
          → 經過小腿、大腿、骨盆 → 另一腳電極回來
          → 中間測電壓降 → 歐姆定律算出阻抗（Ω）
```

**關鍵**：必須**雙腳赤腳同時踩住**四個電極，電路才閉合。
單腳、穿襪子、腳底太乾 → 阻抗測出來是 **0**，體脂率就無從算起。

> 這不是軟體能控制的。任何「發送某個命令就能開啟阻抗」的說法都是錯的——
> 我們做過 A/B 對照實驗驗證（見 [協議文件](PROTOCOL.md) 坑 7）。

### 1.3 這台秤給我們的原始資料

秤在測量完成的鎖定封包裡給出**兩個 ADC 值**（可以理解為左右兩路的原始讀數）：

```
阻抗1 = (d[4] << 8 | d[5])   ← 單位歐姆
阻抗2 = (d[6] << 8 | d[7])
```

正常範圍大約 **100 ~ 1500 Ω**。超出這個範圍的值一律視為無效。

---

## 2. 第一步：把兩個阻抗合成一個

論文裡的公式都只接受**一個**阻抗值，但秤給了兩個。我們的做法：

```
合成阻抗 R = (阻抗1 + 阻抗2) × 0.675
```

### 那個 0.675 是怎麼來的

⚠️ **這個係數不是論文裡的，是我們實測反推的**。

做法：拿官方螞蟻健康 App 在同一時刻顯示的體脂率，反推什麼樣的 R 能讓公式對上。
多組資料擬合後發現約 0.675 能穩定命中（例如 79.95kg + 阻抗 [405, 367] → 官方顯示 37.7%）。

**為什麼會有兩個 ADC**：可能是一路是 50kHz、另一路是另一個頻率（多頻 BIA 的常見做法），
兩路合成的目的通常是抵銷接觸電阻的影響。但廠商沒公開，我們的理解僅為推斷。

### 有效性檢查

```
只有當合成後的 R 落在 100 ~ 1500 Ω 之間，才算有效阻抗
```

---

## 3. BMI（唯一不依賴估算的指標）

```
BMI = 體重(kg) ÷ 身高(m)²
```

例：55.75kg、163cm → 55.75 ÷ 1.63² = **21.0**

**BMI 不含性別、不含年齡**。這是世界衛生組織（WHO）的定義，
所有軟體算出來的 BMI 都應該一樣（只要體重身高一樣）。

所以：切換性別 BMI 不變，是**正確行為**，不是 bug。

---

## 4. 男性體脂率：Deurenberg 公式（不用阻抗）

```
體脂率(%) = 1.10 × BMI + 0.23 × 年齡 − 11.22
```

**來源**：Deurenberg 等人 1991 年發表的種族修正公式（日本人群版本）。
這是**公開論文的原始公式**，我們只用了固定係數，沒有改。

**注意：男性公式裡沒有阻抗**。也就是說，只要知道身高體重年齡，
哪怕沒踩好電極、阻抗為 0，男性體脂率照樣能算。

**實測核對**：79.8kg 男性樣本 → 算出 25.4%，與官方 App 顯示一致。

模型標記：`deurenberg_jp_male`

---

## 5. 女性體脂率：Segal 公式（必須用阻抗）

女性走另一套公式，需要阻抗。

### 5.1 先算「去脂體重」（FFM，Fat-Free Mass）

```
FFM = 體重 − 脂肪的重量    ← 也就是肌肉、骨骼、水分、內臟的總和
```

Segal 公式不直接給體脂率，而是先估 FFM，再用 `100 × (體重 − FFM) ÷ 體重` 反推。

### 5.2 兩個分支：先試 3C，不行再 3D

**分支 A（3C 式，適用於體脂 < 30% 的人）**

```
FFM_A = 10.43485
      + 0.00064602 × 身高²(cm²)
      − 0.01397   × R(合成阻抗)
      + 0.42087   × 體重(kg)
```

先用 A 算出結果，再用它反推體脂率，**如果結果 < 30%，就用這個值**。

**分支 B（3D 式，適用於體脂 ≥ 30% 的人）**

```
FFM_B = 9.37938
      + 0.00091186 × 身高²(cm²)
      − 0.01466   × R
      + 0.29990   × 體重
      − 0.07012   × 年齡
```

> 為什麼分兩段？因為 Segal 公式本來就是針對不同肥胖程度擬合的兩組迴歸線，
> 胖的人用 A 式會系統性低估 FFM。兩段拼接是論文的原意。

**來源**：Segal 等人 1988 年發表於 *American Journal of Clinical Nutrition* 的公式。
原式係數是公開的，我們直接用。

**注意身高單位**：公式裡的身高是 **cm**，平方後是 cm²（如 163² = 26569）。
不是 m²。這裡搞錯會差 10000 倍。

### 5.3 合理性夾擠

```
FFM 被限制在 體重的 35% ~ 97% 之間
```

防止極端輸入（比如阻抗 100Ω 配 30kg 體重）算出離譜結果。

**實測核對**：79.95kg + 阻抗 [405, 367] → 合成 R = 521Ω → 算出 37.7%，與官方一致。

模型標記：`segal_3c_female_lt30` / `segal_3d_female_ge30`

### 5.4 女性沒有阻抗時的兜底

```
體脂率(%) = 1.10 × BMI + 0.23 × 年齡 − 5.4
```

這是 Deurenberg 公式的**女性版本**（男版末尾是 −11.22，女版是 −5.4）。
注意和男性公式對比：同樣的 BMI 和年齡，女性算出來會高 **5.82 個百分點**——
這符合生理事實（女性正常體脂率本來就高於男性）。

模型標記：`deurenberg_jp_female`

---

## 6. 最終夾擠

```
男性體脂率限制在 3% ~ 60%
女性體脂率限制在 8% ~ 60%
```

下限定得不同是因為：男性低於 3% 體脂在生理上幾乎不可能（競技健美極限約 4~5%），
女性低於 8% 會影響內分泌。超過 60% 則基本是測量錯誤。
---

## 7. 其餘指標：都是從體脂率「推」出來的

⚠️ **先說清楚一件事**：這台秤只測了**體重**和**阻抗**兩個量。
下面所有指標都是從上一步算出的體脂率**推導**的，不是分別測量的。

所以理解它們的可信度，要按這個順序：

```
可信度：體重（直接測） > BMI（純數學） > 體脂率（公式估算）> 其他指標（二次推導）
```

### 7.1 脂肪量 / 去脂體重

```
脂肪量(kg)   = 體重 × 體脂率%
去脂體重(kg) = 體重 − 脂肪量
```

純算術，沒有額外假設。

### 7.2 骨量：固定百分比

```
骨量% = 男性 4.5%   /   女性 4.0%
骨量(kg) = 體重 × 骨量%
```

⚠️ **這是寫死的常數，不是測量的**。真實骨密度需要 DEXA（X 光）才能測，
任何家用體脂計的「骨量」都是按人群平均值給的估計值。
我們的取值來自實測反推官方 App 的顯示值。

### 7.3 肌肉量：用減法倒推

```
肌肉% = 100 − 體脂% − 骨量%      （結果限制在 20% ~ 95%）
肌肉量(kg) = 體重 × 肌肉%
```

這個邏輯是「除了脂肪和骨頭，剩下的算肌肉」。
嚴格說這個「剩下」裡還包含內臟、水分、結締組織，但廠商習慣這麼歸類。

### 7.4 水分率：去脂體重 × 係數

```
水分% = (100 − 體脂%) × 係數
係數：男性 0.7185   /   女性 0.8475
（結果限制在 25% ~ 80%）
```

生理學依據：去脂組織（肌肉內臟）含水約 73%；脂肪組織含水約 10~20%。

⚠️ 女性係數 0.8475 明顯高於常用的 0.73，這是實測反推官方 App 的結果。
可能有廠商自己的修正模型，我們按實測值走。

### 7.5 蛋白質：直接按體重比例

```
蛋白質量(kg) = 體重 × 係數
係數：男性 0.163   /   女性 0.05
```

⚠️ **這裡有個需要指出的疑點**：

| 來源 | 男性蛋白佔比 | 女性蛋白佔比 |
| --- | --- | --- |
| 生理學常識 | 約 16~18% | 約 16~18% |
| 我們的實作 | 0.163（合理）| **0.05（明顯偏低）** |

女性的 0.05 是從官方 App 顯示值反推出來的，
**從生理學角度看這個數字不太合理**——它會讓 55.75kg 的女性只顯示 2.8kg 蛋白質，
而實際應該在 9kg 左右。

我們保留它，是為了「和官方 App 保持一致」；如果你更看重生理合理性，
可以把這個係數改成 0.16 左右。**這一項請謹慎引用。**

### 7.6 骨骼肌率：肌肉量 × 係數

```
骨骼肌% = 肌肉% × 係數
係數：男性 0.548   /   女性 0.651
（結果限制在 10% ~ 70%）
```

「骨骼肌」是肌肉裡附著在骨頭上的那部分（區別於心肌和平滑肌）。
通常佔肌肉總量的 55~65%，男女係數不同是實測反推的結果。

### 7.7 皮下脂肪：體脂 × 係數

```
皮下脂肪% = 體脂% × 係數
係數：男性 0.7165   /   女性 0.72
（結果限制在 1% ~ 體脂%）
```

體脂分成「皮下脂肪」（捏得到的那層）和「內臟脂肪」（包在器官周圍的）。
這個係數表示約 72% 的脂肪在皮下。

## 8. 完整計算流程（虛擬碼）

```
輸入：體重 W(kg)、身高 H(cm)、年齡 A、性別、阻抗 [i1, i2]

① BMI = W ÷ (H/100)²

② 合成阻抗 R = (i1 + i2) × 0.675
   若 R 不在 100~1500 區間 → 視為無有效阻抗

③ 算體脂率 bf：
   若 性別=男：
       bf = 1.10×BMI + 0.23×A − 11.22          ← 不需要阻抗
   否則（女）：
       若 R 有效：
           FFM_A = 10.43485 + 0.00064602×H² − 0.01397×R + 0.42087×W
           若 100×(W−FFM_A)/W < 30  →  bf = 100×(W−FFM_A)/W
           否則：
               FFM_B = 9.37938 + 0.00091186×H² − 0.01466×R + 0.29990×W − 0.07012×A
               bf = 100×(W−FFM_B)/W
           其中 FFM 夾擠到 W×0.35 ~ W×0.97
       否則（無阻抗）：
           bf = 1.10×BMI + 0.23×A − 5.4       ← 女性兜底公式

④ bf 夾擠：男 3~60，女 8~60

⑤ 派生：
   脂肪量        = W × bf/100
   去脂體重      = W − 脂肪量
   骨量%         = 男 4.5 / 女 4.0
   肌肉%         = 100 − bf − 骨量%（限 20~95）
   水分%         = (100−bf) × (男 0.7185 / 女 0.8475)（限 25~80）
   蛋白質量      = W × (男 0.163 / 女 0.05)
   骨骼肌%       = 肌肉% × (男 0.548 / 女 0.651)（限 10~70）
   皮下脂肪%     = bf × (男 0.7165 / 女 0.72)（限 1~bf）

⑥ 所有輸出保留 1 位小數
```

對應程式碼：`lib/core/bodycomp.dart`（76 行，無外部依賴，可單獨測試）

## 8.5 實測輸出：同一組資料，男女各算出什麼

拿 `55.75kg / 163cm / 24岁 / 阻抗 430+387` 這組資料，跑完整演算法：

| 指標 | 男性公式 | 女性公式 | 差異 | 說明 |
| --- | --- | --- | --- | --- |
| BMI | **21.0** | **21.0** | **相同** | 純數學，不含性別 |
| 體脂率 | 17.4% | 22.2% | +4.8 pp | 男女走不同公式 |
| 水分率 | 59.4% | 65.9% | +6.5 pp | 女性去脂組織含水係數更高 |
| 骨骼肌率 | 42.8% | 48.0% | +5.2 pp | 係數 0.548 vs 0.651 |
| 皮下脂肪 | 12.5% | 16.0% | +3.5 pp | 隨體脂率走高 |
| 蛋白質量 | **9.1 kg** | **2.8 kg** | 差 6.3 kg | ⚠️ 女性係數 0.05 的已知疑點（見 §7.5）|

模型標記：男性 `deurenberg_jp_male` · 女性 `segal_3c_female_lt30`（合成阻抗 551.5Ω）

> 這張表最想說明兩件事：
> 1. **BMI 一模一樣**——切換性別它不變是設計如此
> 2. **蛋白質那一行是異常**——男女不該差 3 倍，這是逆向係數的遺留問題

## 10. 這套演算法的侷限（重要）

### 10.1 和秤螢幕會差零點幾個百分點

秤屏用的是廠商**私有演算法**（不公開）。我們用的是公開公式 + 校準係數，
所以兩邊會差 **0.3~0.5 個百分點**左右。

**BMI 永遠一致**（純數學，沒有演算法分歧的餘地）。

### 10.2 阻抗受水分影響極大

同樣的身體，不同狀態下阻抗可能差幾十歐姆，對應體脂率差 2~5 個百分點：

| 情況 | 阻抗 | 體脂率讀數 |
| --- | --- | --- |
| 早晨剛起床（略脫水）| 偏高 | 偏高 |
| 剛喝完水 / 剛運動完（充血）| 偏低 | 偏低 |
| 剛洗完澡（皮膚濕潤）| 偏低 | 偏低 |
| 冬天腳底乾燥 | 偏高 | 偏高 |

**正確用法**：固定在同一狀態測（比如每天早上起床後、排尿後、喝水前），
看**趨勢**而不是看單次數值。

### 10.3 不適合的人群

- 孕婦（體液分布特殊）
- 運動員 / 健美（體脂極低時公式外推不準）
- 水腫、腹水、透析患者（體液異常）
- 兒童青少年（生長階段公式不適用）
- 裝有心臟起搏器的人（微弱電流風險，**絕對不要用**）

### 10.4 不是醫療設備

所有數字都是**估算值**，僅供個人趨勢參考，不能用於診斷、治療或任何醫療決策。
需要準確體成分請做 DEXA（雙能 X 射線吸收法）或 MRI。
